# ONECORT · демо CRM для падел-клуба

Демо-версия системы управления падел-клубом: календарь кортов, касса,
клиенты, абонементы, магазин и аналитика.

**Открыть демо:** https://atmosferaprintt.github.io/onecort-demo/demo

Внутри — вымышленный клуб на четыре корта. Данные живут только в браузере
гостя: можно нажимать что угодно, кнопка «Сбросить демо-данные» вернёт всё
в исходное состояние. Ни к какой реальной базе демо не подключено.

Вход в один клик под четырьмя ролями: администратор, владелец (код 7766),
клиент и тренер. Код кассы и аналитики — 7788.

Здесь опубликована только собранная версия для показа. Исходный код —
в отдельном закрытом репозитории.
